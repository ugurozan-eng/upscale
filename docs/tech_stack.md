# Technology Stack

## Frontend
- **Framework:** React + Vite
- **Styling:** TailwindCSS
- **Key Components:** Before/After Slider for images.

## Backend
- **Language:** Python 3.13
- **Framework:** FastAPI
- **Task Queue:** Redis + Celery

## Database & Auth
- **Provider:** Supabase
- **Database:** PostgreSQL
- **Authentication:** Supabase Auth (Google & Email/Password)

## AI & Infrastructure
- **Model:** `recraft-ai/recraft-crisp-upscale` via Replicate API
- **Storage:** DigitalOcean Spaces (S3 Compatible)
- **Deployment:** DigitalOcean
- **Payments:** Lemon Squeezy
